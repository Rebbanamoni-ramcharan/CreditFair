MODEL DESIGN

Why Logistic Regression?

The target variable loan_status contains two classes:

0 Fully Paid
1 Charged Off

Class Imbalance Handling

The dataset contains significantly more fully paid loans than charged-off loans.

CreditFair uses class_weight="balanced" to give additional importance to the minority class.

RESPONSIBLE AI

Fairness Assessment

CreditFair examines model behavior across home ownership groups.

Why Measure Fairness?

A machine learning model should not only produce predictions. Its behavior should also be examined across different groups.

CreditFair compares accuracy, precision, recall and positive prediction rate across home ownership categories.

⚠ Interpretation Notice

The OTHER group contains only 13 evaluation samples. Its metrics should therefore be interpreted cautiously.
